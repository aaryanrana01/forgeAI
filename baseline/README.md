# Human baseline (stretch goal: factory vs human)

`hr_human_agent.json` is an HR agent definition written **by hand** (about 25 minutes of prompt writing),
not by the factory. It uses the same runtime, the same documents and the same output contract, so the only
differences are the prompt, the refusal list and the retrieval parameters.

Compare it with the factory's agent on the factory's own generated eval set:

```bash
python -m forgeai compare --run runs/hr_policy --definition baseline/hr_human_agent.json
# -> runs/hr_policy/06_human_baseline/COMPARISON.md
```

Caveat for the reader: the eval set was generated by the factory, which could favour the factory's agent.
The comparison table lists every case where each side wins so the reader can judge.
